# Recipe Bot — рецепт из любого видео

Присылаешь боту ссылку на Instagram Reels, TikTok или YouTube → получаешь рецепт:
ингредиенты, шаги по порядку, переход к нужному моменту видео. Всё в мини-аппе.

## Что уже работает

Проверено на реальном видео (Ивлев, карбонара, 5:14):
скачалось аудио → расшифровка (4 162 символа, ru) → рецепт: 9 ингредиентов, 13 шагов с таймкодами.

## Как запустить

```bash
cd ~/workspace/recipe-bot
./run.sh
```

Одна команда поднимает всё: сервер, туннель и бота. Ctrl+C — остановить всё разом.

Мини-апп без Телеграма: открой http://127.0.0.1:8891

## Что нужно от тебя

1. **Токен бота.** @BotFather → `/newbot` → токен в `.env` как `TELEGRAM_BOT_TOKEN=...` ✅ уже есть
2. **HTTPS.** Мини-апп в Телеграме открывается только по https. ✅ решено через cloudflared:
   `run.sh` сам поднимает туннель и подставляет адрес в бота. Адрес меняется при каждом
   запуске — поэтому не хардкоди его вручную.
   Без туннеля бот тоже работает — просто присылает рецепт текстом.

## Как это устроено

```
ссылка → yt-dlp (только звук) → ffmpeg (16 кГц моно) → faster-whisper small (локально)
        → LLM (OpenCode Go, deepseek-v4.1-flash) → JSON-рецепт → мини-апп
```

| файл | что делает |
|---|---|
| `app/pipeline.py` | ссылка → аудио → текст → JSON рецепта |
| `app/server.py` | локальный сервер: мини-апп + API `/api/recipe` |
| `app/bot.py` | бот aiogram: принял ссылку, показал кнопку на мини-апп |
| `app/webapp/index.html` | сам мини-апп (один файл, без сборки) |
| `scripts/smoke.py` | проверка без Телеграма |

## Деньги и ресурсы

- Расшифровка — локально на маке, бесплатно (~30 сек на 5 минут видео).
- LLM — по твоей подписке OpenCode Go, копейки за рецепт.
- Диск: `.venv` бота ~40 МБ, модель whisper ~480 МБ (уже скачана).

## Ограничения

- **Instagram** часто отдаёт видео только залогиненным. Если Reels не скачивается —
  нужен файл cookies из браузера (`--cookies-from-browser chrome` в `pipeline.py`).
- TikTok и YouTube обычно работают без входа.
- Видео длиннее 20 минут бот не берёт (защита от часовых стримов).
- Бесконечная история рецептов не хранится: последние — в `~/.hermes/cache/recipe-bot/store/`.
